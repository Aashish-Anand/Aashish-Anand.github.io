# Aashish Anand — Portfolio

A single-page portfolio: `index.html` (no build step). Animation libraries and fonts load from public CDNs
(cdnjs, jsDelivr, Google Fonts), so the page needs nothing installed.

## Publish on GitHub Pages

1. On GitHub (personal account `Aashish-Anand`), create a public repo named **`Aashish-Anand.github.io`**.
   That name makes the site live at `https://aashish-anand.github.io/`.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the repo root (web upload or `git push`).
3. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / root → Save**.
4. Wait 1–2 minutes, then open `https://aashish-anand.github.io/`.

Using a different repo name (e.g. `portfolio`) works too; the site is then at
`https://aashish-anand.github.io/portfolio/`.

## Optional: custom domain

Buy a domain (e.g. `aashishanand.dev`), then in **Settings → Pages → Custom domain** enter it and add the DNS
records GitHub shows. Tick **Enforce HTTPS** once the certificate is issued.

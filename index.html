03 Life as a software engineer

How I work

Six years of shipping search have given me a few habits I keep, whatever the project.

BASELINE

Measure before I build

I write down today's numbers first, so every launch is judged on evidence, including the ones that don't work.

LATENCY

Fast is a feature

In a search box every millisecond is a keystroke. I design for the slowest request, not the average one.

OWNERSHIP

Own it end to end

Design, build, launch, run, hand over. I stay with a system until someone else can run it without me.

LESS

Delete what nobody uses

The cheapest service is the one you switch off. Cleanup is engineering work too.

AI

Use AI as a teammate

I use AI coding agents every day and turn repeated work into tools that whole teams can share.
